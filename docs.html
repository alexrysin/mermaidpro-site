Getting started

  1. In any Confluence page, type /mermaid and choose Mermaid Diagram (Pro).
  2. The editor opens: write Mermaid code on the left, watch the live preview on the right.
  3. New to Mermaid? Click any starter template — Flowchart, Sequence, Gantt, ER, Mindmap, Pie.
  4. Click Save diagram, then publish your page.

Supported diagram types

Everything mermaid.js supports: flowcharts, sequence diagrams, class diagrams, state diagrams, ER diagrams, Gantt charts, pie charts, mindmaps, timelines, user journeys, git graphs, quadrant charts and more. See the Mermaid syntax reference for the full language.

Viewing features

  • Zoom & fullscreen — hover over any diagram to reveal the toolbar: zoom in/out, reset, fullscreen.
  • Export — download any diagram as SVG or retina-quality PNG from the same toolbar.
  • Dark mode — diagrams automatically follow each reader's Confluence theme, re-rendering instantly on switch.
  • Errors — a clear message with the error text instead of a broken page.

Migrating from the legacy Stratus app

If your site used the Connect-era "Mermaid Diagrams for Confluence" app:

  1. Go to Apps → Migrate to Mermaid Pro (site admin recommended).
  2. Click Scan site for Stratus diagrams. The tool finds every legacy diagram and shows a preview of each.
  3. Select the diagrams you want (all selected by default) and click Convert selected.
  4. Each affected page gets a new version with the diagram converted. Original page versions are preserved in page history.
The tool reads the legacy app's diagram source from page attachments — nothing is sent outside your site. The legacy attachments are left untouched; uninstall the old app after verifying the conversion. Full guide: Migrating from Stratus.

Data & security

  • Diagram source is stored in your pages (macro configuration). It never leaves Atlassian's infrastructure.
  • The app is Runs on Atlassian: no external servers, no egress, compatible with data residency.

FAQ

Where is my diagram code stored? Inside the page itself, as macro configuration. It's included in page exports, copies, and history.

Does the app work with Confluence Data Center? No — this app is built on Forge for Confluence Cloud.

What happens if I uninstall? Your diagram code remains in your pages' macro data. Reinstall the app and diagrams render again.

How many diagrams can I create? Unlimited, on every plan.
